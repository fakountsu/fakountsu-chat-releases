# Fakountsu Chat Studio 1.3.0 · предварительная версия

## Изменения

- Новый раздел «Обновления»: проверка новой версии, русские заметки к релизу и установка из приложения.
- Проверка при запуске и выбор предварительных версий. Можно отключить оба переключателя.
- Сборки загружаются из отдельного публичного репозитория, без входа в GitHub. Исходники остаются в закрытом проекте.
- Установка начинается только по нажатию пользователя. После скачивания приложение проверяет размер, SHA256, состав архива и версию исполняемого файла.
- При ошибке замены файлов или неудачном запуске новой версии выполняется возврат предыдущей. Настройки, история и сохранённый вход Twitch находятся отдельно от файлов программы.

## Проверка

- Windows CI собирает приложение под .NET Framework 4.8 и проверяет нативную форму, отрисовку и DPAPI.
- На Windows проверен отдельный процесс установщика: ожидание завершения старого приложения, запуск новой версии, подтверждение старта и возврат/перезапуск предыдущей версии при отказе старта.
- Добавлены проверки выбора канала и версии, контрольной суммы, повреждённых архивов, выхода за папку распаковки, дубликатов, замены файлов и отката при заблокированном файле.
- Существующие проверки чата, восстановления истории, модерации и локального HTTP включены в обязательную сборку.
- Полноценный эфир Twitch/OBS на пользовательском ПК этой сборкой не проверялся.

## Обновление

Версию 1.3.0 нужно один раз скачать и распаковать вручную: в 1.2.1 ещё нет встроенного обновления. Полностью закрой старое приложение через «Выход», распакуй ZIP и запусти FakountsuChat.exe. Данные подхватятся автоматически.

Дальше: раздел «Обновления» → «Проверить обновления» → прочитать изменения → «Скачать и обновить». Приложение заменит файлы в той же папке и перезапустится. Ссылки источников OBS менять не требуется.

## Ограничения

- Обновляй после эфира: перезапуск временно отключает локальный чат. Автоматической установки во время работы нет.
- Предварительные версии включены по умолчанию, поскольку текущий выпуск относится к этому каналу.
- Для загрузки нужен доступ к GitHub и его серверу файлов. При недоступности GitHub чат продолжает работать; проверку можно повторить позже.
- Папка приложения должна быть доступна на запись текущему пользователю. Повышение прав администратора не запрашивается.
- При аварийном выключении Windows во время замены файлов может потребоваться вручную восстановить папку backup из %LOCALAPPDATA%\FakountsuChat\updates. Автоматический откат рассчитан на обрабатываемые ошибки установки и запуска.
- ZIP и SHA256 передаются по HTTPS из одного репозитория. Это проверка целостности; подписи Authenticode пока нет.
