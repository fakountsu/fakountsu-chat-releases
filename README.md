# Fakountsu Chat Studio

Приложение для Windows: Twitch-чат в OBS, настройка оформления и локальный сервер чата.

[Скачать готовую версию](https://github.com/fakountsu/fakountsu-chat-releases/releases)

Распакуй ZIP целиком и запусти `FakountsuChat.exe`. Нужны Windows 10/11, .NET Framework 4.8 и Windows PowerShell 5.1. Ссылки для OBS находятся в приложении.

Начиная с 1.3.0 можно проверять и устанавливать обновления прямо в приложении. Для первого перехода с 1.2.1 скачай 1.3.0 вручную и полностью закрой предыдущую программу через «Выход». Настройки, история и вход Twitch сохранятся.

Обновление перезапускает приложение и временно отключает чат, поэтому устанавливай его после эфира. Программа не управляет сценами или источниками OBS.

В этом репозитории размещены готовые сборки, контрольные суммы и заметки к релизам. Основной проект с исходниками ведётся отдельно.
